# Papagun Desktop

На автоматических слайдах аппаратов, пациентов и процедур пустые и нечисловые план/факт учитываются как ноль в модели отчёта. Исходные книги не изменяются; отрицательные значения остаются ошибкой.

В графиках расходов отсутствующие коды компонентов дают нулевой вклад, повторные строки суммируются. График без единого найденного компонента пропускается. Вкладки выбора показывают только статьи, сопоставимые между двумя книгами.

После сохранения PPTX в сообщении о готовности доступна кнопка «Открыть папку»: она показывает каталог созданного файла в Проводнике Windows. Если файл перемещён или папка не открылась, приложение показывает ошибку рядом с результатом.

Если выбранный PPTX открыт и Windows не разрешает заменить его, приложение сохраняет новый отчёт в той же папке под свободным именем с номером, например `Papagun_отчёт (2).pptx`. Сообщение показывает фактический путь; ранее созданный файл не меняется.

Локальное приложение Tauri 2 + React + TypeScript. Обработчик `engine.py` вызывает проверенные функции расчёта и построения редактируемых слайдов из `excel_loading.ipynb`.

В правых итоговых блоках расходных страниц процент показывается и на количественных, и на финансовых слайдах: сумма «Факт по 1С» / сумма «Факт по норме» × 100 по выбранным филиалам и месяцам. Подпись округляется до целого процента.

На количественных страницах два первых столбца правого итога показывают именно суммы нормы и факта 1С; филиальные графики сохраняют план «Утверждено» и факт 1С.

На четырёх заключительных страницах все выбранные филиалы подписаны под углом 45° и отдельно сортируются по доле каждого показателя. Числовые метки долей расположены горизонтально и показаны с одной десятичной цифрой без знака `%`. На диаграммах с рядом «отк:» филиалы идут по убыванию отклонения.

Период в заголовке выборочного отчёта зависит от выбора: один месяц, два названных месяца, «за квартал», «за полугодие» или «за год» для полного календарного периода. Подписи диаграмм и названия показателей увеличены.

## Разработка

Требуются Node.js, Python с пакетами из `requirements-engine.txt`, Rust MSVC toolchain и Visual Studio C++ Build Tools. Скрипт сборки сам находит установленный MSVC toolchain. В корне проекта:

```powershell
python -m pip install -r app/requirements-engine.txt
Set-Location app
npm.cmd ci
npm.cmd exec tauri -- dev
```

В режиме разработки Tauri запускает `python app/engine.py`. Рабочий экспорт собирает слайды в памяти и сохраняет только один выбранный итоговый PPTX. Отдельные тестовые презентации и тестовый скрипт в приложении отсутствуют.

На Windows обработчик запускается без отдельного консольного окна. При чтении книг и построении презентации интерфейс показывает текстовый статус с индикатором обработки; при системной настройке уменьшения движения анимация отключена.

## Сборка Windows

Бюджетные книги пользователя и справочник коротких названий центров в EXE не включаются. Подписи филиалов берутся из листа `Филиалы` выбранных книг. Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File app/build-windows.ps1
```

Скрипт упаковывает Python, notebook и логотип в sidecar, затем собирает Tauri NSIS установщик. Настройка `offlineInstaller` включает автономный установщик WebView2; установка и работа готового приложения не требуют сети. Проверенный результат сборки от 2026-11-03: `app/src-tauri/target/release/bundle/nsis/Papagun_0.1.0_x64-setup.exe` (316,39 MiB). Самостоятельный EXE находится в `app/src-tauri/target/release/papagun.exe`; для запуска рядом с ним нужен `papagun-engine.exe`, поэтому для пользователей предназначен установщик.

В каждой выбранной бюджетной книге нужен лист `Филиалы` с колонками `Название филиала` и `Название листа`. Приложение загружает перечисленные в нём листы, показывает названия из первой колонки и строит отчёт по `quantity_df` и `financial_df`.

В интерфейсе выбирается пара совместимых количественной и финансовой книг. Загрузчик распознаёт заголовки и границы таблиц по содержимому листов, а не по заранее заданному числу строк. Месяцы и филиалы выбираются плитками: щелчок выбирает один пункт, Shift + щелчок добавляет диапазон, Ctrl + щелчок добавляет или снимает пункт. Недоступные для текущего отчёта плитки отключены. Вкладки статей показывают только присутствующие в количественной книге поддерживаемые разделы 211/212/213. Для лекарств, медицинских изделий и расходных материалов можно выбрать исходные позиции или объединить несколько позиций одного раздела в именованный показатель. Один выбор применяется к обеим книгам: разные названия при одинаковом коде между книгами связываются, а внутри книги позиции одного кода с разными названиями остаются отдельными.

Именованные шаблоны сохраняют месяцы, филиалы, выбранные статьи и группы на этом компьютере. Книги Excel и пути к ним в шаблон не входят. После загрузки пары книг выберите шаблон и нажмите «Загрузить»; если его позиции недоступны в новых книгах, текущий выбор не меняется и приложение показывает причину. В каждой вкладке статей есть «Выбрать все» и «Снять выбор»; при поиске первое действие выбирает только найденные статьи.

Итоговый PPTX начинается с аппаратов, пациентов и процедур. Эти три слайда создаются без выбора статей: план и факт каждого показателя суммируются по всем выбранным месяцам и филиалам; заголовок отражает выбранный период. Затем для выбранных статей каждого раздела следуют количественная, финансовая и квартальная страницы: пары показателей, а при нечётном количестве от трёх — последняя тройка. После двух страниц финансовых расходов по транспортным и пищевым статьям добавляются четыре страницы с двенадцатью долями расходов от «ВСЕГО РЕАЛИЗАЦИЯ». Они рассчитываются по «Факт по 1С» финансовой книги для выбранных месяцев и филиалов; каждый график сортируется по доле по убыванию. Состав показателей и правила пропусков описаны в `docs/DATA_CONTRACT.md`. На квартальных страницах выбранные кварталы занимают от одной до четырёх позиций перед фиксированным итогом справа; пустые кварталы не показываются. Четвёртый квартал доступен, когда обе книги содержат его месячные данные. Группы статей сначала проверяются по компонентам и суммируются только в модели отчёта. Пустая ячейка, нечисловой текст, ошибка Excel и отсутствующий месяц выбранной статьи входят в сумму как ноль; при нулевом знаменателе процент исполнения отображается как 0%. Отрицательное число останавливает расчёт. Исходные XLSX не изменяются. Приложение сохраняет один итоговый PPTX в выбранное место.
