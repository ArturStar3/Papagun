# Papagun

Локальное приложение для Windows на Python, которое преобразует данные из Excel в презентацию установленного формата. Конечный пользователь запускает приложение через .exe без отдельной установки Python.

## Рабочий процесс
1. Выбрать исходные Excel-книги.
2. Загрузить нужные листы и проверить структуру.
3. Очистить и привести данные по явным правилам.
4. Подготовить показатели и применить согласованные фильтры.
5. Сформировать презентацию и сохранить результат в выбранное место.

## Состояние проекта
Создана документационная основа и [Jupyter Notebook для загрузки Excel](excel_loading.ipynb). Чтение обеих книг через pandas проверено; схема данных и формат слайдов ещё не утверждены. Код приложения, сборка и установщик пока отсутствуют.

## Работа с Excel в Jupyter
Откройте `excel_loading.ipynb` в Jupyter или редакторе с поддержкой notebooks и выберите Python-ядро с `pandas` и `openpyxl`. Если окружение ещё не подготовлено, установите `python -m pip install pandas openpyxl notebook` и запустите `python -m notebook` из корня проекта.
Выполните ячейки сверху вниз: все листы двух книг будут доступны в словарях `financial_sheets` и `quantity_sheets`, а их размеры — в `sheet_summary`. Раздел «Единый DataFrame филиалов» формирует `branches_df` из количественного бюджета: филиал, статья, месяц, утверждено, факт по норме и факт по 1С. Координаты источников доступны в `branches_provenance`, ошибки Excel — в `branches_diagnostics`. Итоговые строки и повторяющиеся названия сохраняются; правила расчётов ещё не согласованы. Перед сохранением очищайте результаты ячеек, содержащие данные таблиц.
