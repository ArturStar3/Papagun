# Papagun

Локальное приложение для Windows на Python, которое преобразует данные из Excel в презентацию установленного формата. Конечный пользователь запускает приложение через .exe без отдельной установки Python.

## Рабочий процесс
1. Выбрать исходные Excel-книги.
2. Загрузить нужные листы и проверить структуру.
3. Очистить и привести данные по явным правилам.
4. Подготовить показатели и применить согласованные фильтры.
5. Сформировать презентацию и сохранить результат в выбранное место.

## Состояние проекта
Создана документационная основа и [Jupyter Notebook для загрузки Excel](excel_loading.ipynb). Чтение обеих книг через pandas проверено. Реализован и проверен отдельный аналог второго слайда презентации NL через python-pptx из quantity_df. Полная схема показателей и остальных слайдов ещё не утверждена; UI, сборка и установщик пока отсутствуют.

## Работа с Excel в Jupyter
Откройте `excel_loading.ipynb` в Jupyter или редакторе с поддержкой notebooks и выберите Python-ядро с `pandas` и `openpyxl`. Если окружение ещё не подготовлено, установите `python -m pip install pandas openpyxl notebook` и запустите `python -m notebook` из корня проекта.
Выполните ячейки сверху вниз: все листы двух книг будут доступны в словарях `financial_sheets` и `quantity_sheets`, а их размеры — в `sheet_summary`. Читаются `Исходники/NL_Кол. Бюджет.xlsx` и `Исходники/NL_Фин. Бюджет.xlsx`. Отдельные таблицы `quantity_df` и `financial_df` содержат филиал, статью, месяц, утверждено, факт по норме и факт по 1С. Координаты источников доступны в `quantity_provenance` и `financial_provenance`, ошибки Excel — в `quantity_diagnostics` и `financial_diagnostics`. `dataframe_summary` показывает размеры и число ошибок. Прежние переменные `branches_*` ссылаются на количественный бюджет. Итоговые строки и повторяющиеся названия сохраняются; правила расчётов ещё не согласованы. Перед сохранением очищайте результаты ячеек, содержащие данные таблиц.

## Аналог второго слайда
`slide2_export.py` формирует один редактируемый слайд о пациентах из `quantity_df` и `quantity_provenance`; вызов добавлен в конец notebook. Установите дополнительную зависимость `python -m pip install -r requirements-slide2.txt` в используемое ядро.

В текущем проекте подготовлено локальное `.venv` с доступом к уже установленным pandas/openpyxl. Из корня проекта: `.venv\Scripts\python tools/build_slide2.py`. Результат: `output/NL_пациенты_2026_слайд2.pptx`. Если файл уже существует, укажите новое имя: `.venv\Scripts\python tools/build_slide2.py --output output/slide2_v2.pptx`. Исходники и существующие результаты не перезаписываются.

Период подтверждён пользователем: сентябрь, численность на конец 9 месяцев. Используются 18 центров исходного слайда, строка Excel 14, план «Утверждено» и факт «Факт по 1С». Это реализация данного примера; использование этой статьи и состава центров для следующих отчётов ещё требует подтверждения. Сводка пересчитывается по показанным столбцам. Расхождения исходного образца и методика описаны в `docs/SLIDE2.md`. Проверка: `.venv\Scripts\python tools/verify_slide2.py` (использует временный каталог, готовый результат не затрагивается).

## Исходные материалы
Текущие книги NL находятся в папке «Исходники»; прежние материалы в корне сохранены. Точные имена и назначение перечислены в docs/PROJECT_CONTEXT.md. Они считаются неизменяемыми источниками; новые результаты сохраняются отдельно.
