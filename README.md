# Papagun

Локальное приложение для Windows на Python, которое преобразует данные из Excel в презентацию установленного формата. Конечный пользователь запускает приложение через .exe без отдельной установки Python.

## Рабочий процесс
1. Выбрать исходные Excel-книги.
2. Загрузить нужные листы и проверить структуру.
3. Очистить и привести данные по явным правилам.
4. Подготовить показатели и применить согласованные фильтры.
5. Сформировать презентацию и сохранить результат в выбранное место.

## Состояние проекта
Создана документационная основа. Код приложения, зависимости, сборка и установщик пока отсутствуют. Существующие Excel и PPTX ещё не проанализированы; формат данных и слайдов не утверждён.
