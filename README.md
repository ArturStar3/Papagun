# Papagun

Локальное приложение для Windows на Python: Excel → проверка и подготовка данных → презентация установленного формата. Конечный продукт будет запускаться через .exe без отдельной установки Python.

## Текущий этап — Jupyter Notebook

По поручению пользователя весь код подготовки находится в [excel_loading.ipynb](excel_loading.ipynb): загрузка, DataFrame, расчёты, генерация PPTX, тесты и необязательный просмотр через PowerPoint. Собственных .py/.ps1-модулей и импортов из них нет. К GUI и выделению .py перейдём после подготовки и согласования правил.

Откройте notebook, выберите Python-ядро и выполняйте ячейки сверху вниз из корня проекта. Ядру нужны pandas, openpyxl и python-pptx 1.0.2. Пример установки для нового окружения: `python -m pip install pandas openpyxl python-pptx==1.0.2 notebook`, запуск интерфейса: `python -m notebook`. Дополнительная зависимость экспорта закреплена в requirements-slide2.txt. Полное окружение пока не зафиксировано; локальная .venv использует уже установленные pandas/openpyxl через system-site-packages.

## Что делает notebook

Если возникает `ModuleNotFoundError: No module named 'pptx'`, выполните отдельную ячейку `%pip install python-pptx==1.0.2`, перезапустите ядро и запустите notebook сверху вниз. В начале notebook добавлена проверка зависимостей выбранного ядра. При `INSTALL_MISSING_DEPENDENCIES=True` она устанавливает только отсутствующие пакеты через Python текущего ядра; по умолчанию установка выключена и сеть не используется.

1. Читает Исходники/NL_Кол. Бюджет.xlsx и Исходники/NL_Фин. Бюджет.xlsx. Все листы доступны в quantity_sheets/financial_sheets, размеры — в sheet_summary.
2. Формирует quantity_df и financial_df: филиал, статья, месяц, утверждено, факт по норме, факт по 1С. Происхождение и ошибки хранятся отдельно; branches_* оставлены как ссылки на количественные результаты.
3. Создаёт редактируемый аналог второго слайда: сентябрь, численность на конец 9 месяцев, 18 центров образца, строка Excel 14, план «Утверждено» и факт «Факт по 1С». Статья и состав центров не утверждены как общие правила остальных отчётов.
4. Проверяет значения и ошибочные входы, формирует один тестовый PPTX с 15 слайдами: пациенты на 1/3/6/11/18 центрах, процедуры на 1/3/6/11/19 и нагрузка на аппараты на 1/3/6/11/18. Малая выборка не растягивает столбцы.
5. По желанию показывает превью через установленный PowerPoint, проверяя переполнение текста и перенос чисел.

## Настройки

В начале notebook: OUTPUT_DIR, REPORT_MONTH, BRANCH_COUNTS, PROCEDURE_BRANCH_COUNTS, LOAD_BRANCH_COUNTS, GENERATE_PRESENTATIONS, RUN_CHECKS, RENDER_PREVIEWS. По умолчанию экспорт и проверки включены, PowerPoint-превью выключены. Генерация создаёт только итоговый PPTX (3 слайда) и общий тестовый PPTX (15 слайдов). Имена выбираются свободными; исходники и существующие результаты не перезаписываются. Промежуточные слайды и шаблоны временные.

В output сохраняются только PPTX. Превью и диагностический JSON при включении просмотра создаются во временной папке и удаляются после показа. Перед сохранением очищайте outputs; показатели и локальные пути не должны оставаться в сохранённых результатах ячеек.

## Состояние и ограничения

Самостоятельное выполнение всех кодовых ячеек через Python проверено после удаления отдельных модулей. Регрессионные проверки и пять количеств филиалов прошли; рендер из notebook проверен через PowerPoint. Запуск в интерфейсе Jupyter и проверка пакетом nbformat не выполнялись. Кэш формул Excel не пересчитывается. Связи книг, общие правила расчётов, фильтры и остальные слайды ещё требуют исследования. GUI и сборки EXE пока нет.

## Пациенты и процедуры в одном результате

Notebook собирает аналог третьего слайда: процедуры за подтверждённый период январь–сентябрь, 19 центров образца. По последнему поручению в `quantity_df` и `financial_df` оставлены только 12 действительных месяцев. Процедуры за девять месяцев рассчитываются суммой января–сентября из `quantity_df` по согласованию пользователя; пациенты остаются сентябрьским срезом. Готовый сводный блок Excel в текущий расчёт не входит: для одного филиала он ранее расходился с месячной суммой. `report_path` содержит общий PPTX с пациентами и процедурами. Общий тест — второй PPTX с 10 слайдами, отдельные слайды на диск постоянно не сохраняются. Реализация и проверки — [docs/SLIDE3.md](docs/SLIDE3.md).

## Нагрузка на аппараты

Аналог четвёртого слайда в notebook считает сентябрьскую нагрузку отдельно для плана и факта: пациенты из строки 14 / аппараты из строки 13 `quantity_df`. Диаграмма показывает фактическую нагрузку по 18 центрам, сводка — число аппаратов и отношение общих сумм пациентов и аппаратов. Формула подтверждена пользователем; выбор периода и строк относится к данному образцу. Подробности и проверки — [docs/SLIDE4.md](docs/SLIDE4.md).

## Генератор слайдов 3–34

Отдельный модуль [generate_presentation.py](generate_presentation.py) читает те же книги NL, добавляет готовые блоки периодов Excel и собирает PPTX по слайдам 3–34 шаблона. Запуск: `python generate_presentation.py` из корня проекта. Ноутбук при этом не изменяется. Неоднозначные статьи, диаграммы периодов без правила итога сети и слайды 4, 30–33 не заполняются угаданными числами. Категории и имена рядов совпадают с эталоном; сами числа эталона из текущих книг почти не воспроизводятся. Описание алгоритма, сравнения и слабых мест — [docs/PRESENTATION_GENERATOR.md](docs/PRESENTATION_GENERATOR.md).
