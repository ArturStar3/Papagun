## Реестр филиалов в книгах — D-043

В каждой книге NL лист `Филиалы` содержит колонки `Название филиала` и `Название листа`. Первая колонка задаёт значение `Наименование филиала` в `quantity_df` или `financial_df`, вторая указывает лист для чтения. Загружаются только листы, перечисленные в реестре соответствующей книги. Фактическое имя листа сохраняется в таблице происхождения; расчёты и презентация получают уже построенные DataFrame. Пустые и повторные названия, отсутствующий или неоднозначный лист блокируют загрузку.

В предоставленных книгах реестр содержит «Атырау Нурсая2», а фактический лист — «Атырау Нурсая 2». ## Выборочный отчёт приложения — 2026-10-29

Уточнение D-039: каталог выбора берётся только из количественной книги. Его ключ — `(код, точное наименование)`; две строки одного кода с разными названиями не схлопываются. Для финансовой книги сначала отбирается тот же код. Если финансовое название одно, различие текста между книгами допустимо; если названий для кода несколько, требуется точное совпадение с выбранным количественным названием, иначе экспорт останавливается как неоднозначный. Один выбор создаёт количественную и финансовую части одного итогового PPTX. Это правило заменяет ниже упоминание отдельных пар выбора для каждой книги.

Приложение принимает две выбранные книги `.xlsx` структуры NL и использует только месяцы и филиалы пользователя. Код сохраняется строкой без краевых пробелов. Для количественного слайда используются «Утверждено», «Факт по 1С» и «Факт по норме − Факт по 1С»; для финансового — «Факт по норме», «Факт по 1С» и разность, в тыс. тенге. Модели и разрешённые точечные нули выполняют функции `excel_loading.ipynb`. Остальные пропуски блокируют построение.

Актуальная навигационная группировка каталога: 211 — лекарства, 212 — изделия, 213 — расходные медицинские материалы. Строки с первой частью кода меньше 200 и от 214 не показываются по D-041/D-042. Группировка служит навигации и **не считается согласованной финансовой классификацией**; требуется подтверждение по иерархии книг.

Статус: схема первичного объединения листов филиалов установлена для текущих книг; единицы, связи и правила бизнес-расчётов ещё не согласованы.

Актуальный экспорт — 18 основных и 90 тестовых слайдов непосредственно в excel_loading.ipynb. По D-019 все макеты создаются программно; входная презентация и прежние PPTX не требуются. Исторический шаблонный генератор 3–34 выведен из использования. Для кодов 211.11/211.12 записи сохранены в output. Имена статьи кода 211.11 в книгах различаются по дозировке; каждое отображается только на своём слайде.

## Готовый девятимесячный период процедур в notebook

## Правила обработки
Не исправлять данные молча. Каждое преобразование имеет правило и проверяемый пример.
Пустое значение, ноль и ошибка ячейки — разные состояния.
Учитывать десятичные разделители, пробелы, проценты, даты и локаль.
Не удалять дубликаты, пока не определён ключ и правило их разрешения.
Для денежных показателей определить точность и момент округления; не полагаться на двоичный float для точных финансовых расчётов.
Для формул определить использование сохранённых значений: openpyxl не пересчитывает Excel-формулы. Отсутствие или устаревание кэша должно иметь согласованную обработку.
Разделять критические ошибки, блокирующие экспорт, и предупреждения, допускающие продолжение.
Сохранять числа как числа до форматирования для слайдов.
