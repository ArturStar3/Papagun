# Исследование презентации и аналог слайда 2

Дата: 2026-10-22.

## Объём исследования
Локально прочитан PPTX из папки «Исходники», содержащий 34 слайда формата 16:9. Структурно просмотрены заголовки и количество диаграмм: пациенты, процедуры, нагрузка на аппараты, лекарственные средства, расходные материалы и финансовые показатели. Подробно исследован только слайд 2; семантика остальных слайдов не установлена.

Слайд 2: одна редактируемая столбчатая диаграмма по 18 центрам, план и факт, проценты исполнения, заголовок, сводка и логотип. В оригинале проценты сделаны третьей серией с ручным расположением подписей. План бирюзовый, факт серый; центры упорядочены по убыванию исполнения. Шрифт диаграммы Arial Narrow, подписи центров вертикальные.

## Найденные расхождения
- Заголовок говорит о 9 месяцах. Проверенные пары значений для Актобе, Атырау и Актобе АМЦ совпадают с июньской строкой 14 текущего количественного бюджета, а не с сентябрём. Полное совпадение исходного слайда с июнем по всем центрам не утверждается.
- Общая сводка исходного слайда не совпадает с суммами его серий. Числовые показатели образца в документацию не копируются.
- Справочник названий содержит 19 центров, исходный слайд — 18, DataFrame — 20 филиалов. Состав исходного слайда сохранён: Атырау Нурсая и Атырау Нурсая 2 в этот аналог не входят. Это состав конкретного образца, а не общий бизнес-фильтр.

## Использованные данные
Подтверждено пользователем: сентябрь, численность на конец 9 месяцев; месяцы не суммируются.

Для данного примера используются `quantity_df` и соответствующая таблица происхождения, строка Excel 14 «Количество пациентов». Координата отличает её от одноимённых строк сателлитов и услуг. План — «Утверждено», факт — «Факт по 1С». Финансовый DataFrame не используется. Статья и колонка факта для общего продукта ещё требуют подтверждения.

Названия сопоставляются через предоставленный справочник центров, с проверкой соответствия каждого центра одному филиалу. Учтены пробелы, переносы, дефисы, «12 мкрн.»/«12 мкр» и суффикс `(NL UK)` в имени листа. Неподобранное или неоднозначное название блокирует генерацию.

Исполнение = факт / план. Отклонение = факт − план. Общие план и факт = суммы только показанных центров; общее исполнение = общий факт / общий план. Расчёт через Decimal без округления исходных значений; отображение исполнения с одним десятичным знаком, ROUND_HALF_UP. Цвет процентов повторяет образец: ниже 95% красный, иначе синий. Это воспроизведение оформления примера, не утверждённый порог оценки деятельности.

Отсутствие значения, ошибка Excel, отрицательное или дробное число пациентов, нулевой план, изменение статьи либо несогласованные индексы DataFrame/происхождения блокируют генерацию. Пропуски не заменяются нулями.

## Реализация
`slide2_export.py` использует python-pptx 1.0.2. Оформление берётся из второго слайда источника, остальные слайды и связь с заметками удаляются. `Chart.replace_data` заменяет категории, обе серии и встроенную XLSX данными DataFrame. Проценты — отдельные редактируемые рамки; старые ручные подписи и тени заменены, расстояния столбцов настроены для двух серий. Исходная презентация не сохраняется.

В notebook добавлена ячейка вызова `build_slide2`. CLI `tools/build_slide2.py` выполняет существующие ячейки загрузки notebook в памяти, пропуская ячейку экспорта, и передаёт их DataFrame генератору. Результаты ячеек не сохраняются. Генерация в папку исходников и перезапись результата заблокированы.

Выходные материалы в игнорируемой папке `output/`: `NL_пациенты_2026_слайд2.pptx` и одноимённое PNG-превью. Это отдельный слайд, не замена полного исходного отчёта.

## Ограничения
Кэш Excel не пересчитывается и его актуальность не доказана. Взаимосвязь сателлитов, пациентов по видам услуг и общей численности ещё не согласована; генератор использует только указанную строку. Общее правило состава центров и дальнейшие слайды требуют согласования. Выбранная технология экспорта проверена для этого слайда, а не для всех объектов презентации.
