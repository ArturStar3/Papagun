# Пациенты — аналог слайда 2

Актуальная реализация: D-019, 2026-10-27. Весь код находится в excel_loading.ipynb. Слайд создаётся с нуля без входной презентации; стиль и список 18 центров заданы в коде, логотип — отдельный JPG.

## Данные и расчёты

Подтверждённый период — сентябрь, численность на конец девяти месяцев. Используются quantity_df и происхождение, строка Excel 14 «Количество пациентов». План — «Утверждено», факт — «Факт по 1С». Одноимённые строки других разделов не объединяются, месяцы не суммируются. Справочник сопоставляет явные подписи центров с филиалами; учтён суффикс (NL UK).

Исполнение = факт / план; отклонение = факт − план. Итоги — суммы показанных центров. Числа пациентов должны быть целыми неотрицательными, пропуск/ошибка и нулевой план блокируют экспорт. Decimal используется до записи диаграмм; общий процент показывается с одним знаком, ROUND_HALF_UP. Цвет рамок повторяет согласованный прототип: ниже 95% красный, иначе синий; итоговая сводка красная при факте ниже плана. Это два отдельных сохранённых правила оформления.

## Представление и проверки

Редактируемая столбчатая диаграмма и XLSX создаются программно. План бирюзовый, факт серый; порядок — убывание исполнения. Проценты — текстовые рамки. Компактная область столбцов центрируется при малом наборе; названия и числовые подписи вертикальные. Тестовые наборы — 1/3/6/11/18.

Проверяются независимые сентябрьские ячейки Excel, значения/категории/серии, итоги, проценты, геометрия, XLSX и ошибочные входы. Холодный запуск проверяется с запретом внешних PPTX. Основной файл содержит четыре показателя, тестовый — двадцать слайдов.

## Исторические особенности образца

Исходный слайд за девять месяцев имел расхождения периода и общей сводки; новый расчёт всегда следует подтверждённому сентябрю и показанным центрам. Указанные ранее клонирование слайда, TEMPLATE и сохранение исходного XML больше не используются. Состав центров — правило этого прототипа, не общий бизнес-фильтр. Кэш формул Excel не пересчитывается.
