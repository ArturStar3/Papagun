# Концепция проекта

Обновлено: 2026-10-29. По новому поручению пользователя начат этап GUI на Tauri 2 + React + TypeScript + Vite. Прежнее ограничение «весь код только в notebook до GUI» относится к завершённому этапу подготовки; интерфейс и локальный обработчик теперь находятся в `app/`. Python сохраняется для расчётов, а интерфейс упаковывается в Windows EXE. Текущий продукт создаёт выборочный отчёт, а полный согласованный формат 34 слайдов остаётся отдельной открытой задачей.

Уточнение D-039: список статей в приложении строится только по количественной книге. Одно выбранное значение используется для построения количественной и финансовой частей итогового PPTX. Между книгами совпадение кода связывает разные названия; внутри книги одноимённый код с разными названиями остаётся разными позициями.
