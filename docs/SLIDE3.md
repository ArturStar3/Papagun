## Данные и представление

- Источник — количественный бюджет NL, строка 15 «Количество процедур». Другие строки с тем же названием не объединяются.
- По уточнённому поручению D-014 данные берутся только из основных `quantity_df`/`financial_df`: при первоначальной подготовке обеих таблиц читаются 12 месяцев и готовый период «9 месяцев». Поле «Месяц» и шесть колонок сохранены. Дополнительных таблиц периодов нет. Процедуры и пациенты используют `quantity_df` с его таблицей происхождения; `financial_df` подготовлен для финансовых слайдов.
- План и факт — готовый блок «9 месяцев», CI15 и CK15. Суммирование месяцев не применяется: при проверке всех 20 филиалов у одного сумма не совпала с готовым блоком. Причина расхождения не установлена.
- Используются 19 центров третьего слайда образца и предоставленный справочник. Это состав данного прототипа, не общий фильтр. Пациентский слайд сохраняет свои 18 центров.
- Исходные дробные значения процедур сохраняются: диаграмма и встроенная XLSX не приводят их к целым. Формат General не добавляет пустой десятичный разделитель. Общий формат округления остальных показателей этим не утверждается.
- Сортировка по убыванию исполнения; исполнение = факт / план, отклонение = факт − план. Итоги относятся только к показанным центрам. Проценты, цвета и редактируемые рамки используют алгоритм пациентского слайда.
- Пропуск, ошибка Excel, отрицательное/бесконечное значение, нулевой план, неверная статья или происхождение блокируют экспорт. Для пациентов прежнее ограничение целых значений сохранено.

## Результат и запуск

Выполнять notebook сверху вниз. По D-015 `build_slide3` и `build_slide2` — вспомогательные функции с обязательным output для временных файлов; `build_report` собирает пациентов и процедуры в один PPTX. `report_path` указывает на итог со свободным именем `output/NL_пациенты_процедуры_2026.pptx`.
