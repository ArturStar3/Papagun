## Ограничения
- Формулы не пересчитываются. Используется сохранённый кэш Excel, его полнота и актуальность отдельно не проверены.
- Пустые значения сохранены как pd.NA, ошибки — как текстовые коды. Перед расчётами нужно согласовать их обработку; пропуски не заменяются нулями.
- Список филиалов и диапазоны заданы явно для проверенных книг; при смене версии нужна повторная проверка.
- Общие правила итогов, повторяющихся статей, единицы, связи книг, фильтры и формат остальных слайдов ещё не согласованы. Слайд 2 и справочник исследованы в рамках прототипа; книги FMNQ/BBN не исследованы.
- Для запуска требуется Python-ядро с pandas и openpyxl; версии не закреплены. По умолчанию ядро запускается из корня проекта, иначе нужно изменить DATA_DIR.
- DataFrame создаются в памяти при запуске notebook; отдельный экспорт таблиц не реализован и не запрошен. Значения показателей в файле ноутбука не сохранены.
- Аналог использует только основную численность строки 14; включение сателлитов/других разделов и состав центров для дальнейшего продукта не согласованы. Сохранённые значения формул не пересчитываются. Полная генерация 34 слайдов и интерактивный запуск notebook не проверены.
