## Ограничения

- Кэш формул Excel не пересчитывается; полнота и актуальность не доказаны. Пропуски остаются pd.NA, ошибки — кодами Excel, нули сохранены.
- Списки листов и диапазоны заданы для проверенных книг; смена версии требует повторной проверки.
- Строка 14, колонка факта и 18 центров — реализация данного примера, а не общее согласование состава отчётов. Проверены только пять количеств и установленный PowerPoint; другие просмотрщики, масштабы и более 18 центров не проверялись.
- Единицы, связи книг, общие правила итогов/повторов, фильтры и остальные слайды не согласованы. Книги FMNQ/BBN не исследованы.
- Данные создаются в памяти; отдельный экспорт DataFrame не запрошен. Полное окружение не закреплено; Jupyter-ядру нужны библиотеки из README. Для запуска требуется рабочая папка проекта.
- GUI, полный отчёт из 34 слайдов, сборка EXE и проверка Windows без Python пока отсутствуют. Их реализация будет следующим этапом после подготовки.
