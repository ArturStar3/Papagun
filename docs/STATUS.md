- Сформировано 31 908 строк для 20 филиалов и 12 месяцев. Итоги и повторяющиеся названия сохранены. Пустые показатели представлены pd.NA; нули не изменены.

- Обновлены README, концепция, журнал решений и план; .ipynb_checkpoints/ исключены из Git.

## Текущее состояние и ограничения
Загрузка Excel и преобразование месячных блоков филиалов проверены. Структура источника и правила первичного извлечения описаны в DATA_CONTRACT.md. Связи, единицы, правила агрегации, фильтры и формат слайдов ещё не утверждены; PPTX не исследован. Код приложения и сборка EXE отсутствуют.
Словарь DataFrame не сохраняет оформление и объединённые ячейки Excel; формулы при чтении не пересчитываются. Отсутствующий или устаревший кэш формул отдельно не проверяется. Ошибки Excel сохранены текстовыми кодами: перед расчётами необходимо их разобрать. Повторяющиеся статьи и итоговые строки не следует суммировать без согласованного правила.
Список из 20 филиалов задан явно. Основная таблица количественной книги — строки 9–141; вспомогательные алгоритмы ниже исключены. При смене версии книг список и границы нужно проверить заново. Отдельный финансовый источник поддержан, но в итоговый DataFrame по умолчанию не входит.
Для notebook нужно выбрать Python-ядро с pandas и openpyxl; пакеты ядра не закреплены в файле проекта. При запуске из другой папки задайте DATA_DIR. Инструкция запуска Jupyter приведена в README и ноутбуке.
Исходные книги бюджета остаются локально и не изменялись. Ранее git status останавливался из-за dubious ownership; настройка Git не изменялась.
