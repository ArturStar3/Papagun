# План развития

Отметка выполнено означает наличие проверенного результата, а не только плана.

- [x] Этап 0: документационная основа, инструкции, контекст, стиль и журнал решений.
- [ ] Этап 1: исследовать книги и презентацию; описать схемы источников, связи, показатели и слайды; согласовать спорные правила.
  - [x] Создать Jupyter Notebook и проверить загрузку всех листов двух XLSX через pandas.
  - [x] Исследовать месячные блоки листов филиалов и сформировать единый DataFrame количественного бюджета; общая схема показателей и PPTX ещё требуют исследования.
- [ ] Этап 2: выбрать версии Python и библиотек; создать минимальную структуру, окружение и первый сквозной сценарий на одном согласованном слайде.
- [ ] Этап 3: реализовать импорт, проверки и нормализацию с диагностикой и контрольными примерами.
- [ ] Этап 4: реализовать расчёты и отчётную модель; сравнить результаты с согласованными эталонами.
- [ ] Этап 5: реализовать полный экспорт по установленному формату и проверить презентацию визуально.
- [ ] Этап 6: собрать UI в едином стиле, обработку длительных операций и состояний.
- [ ] Этап 7: добавить фильтры после определения их состава и влияния на расчёты.
- [ ] Этап 8: собрать и проверить Windows EXE, подготовить инструкции пользователя и выпуск.

Этапы можно выполнять частично параллельно. Первый сквозной сценарий должен проверить техническую реализуемость до масштабирования на все слайды.
