# Препараты — аналог слайда 5

Актуальная реализация: D-019, 2026-10-27. Слайд программно создаётся с нуля в excel_loading.ipynb. Входная презентация, готовый слайд и существующие результаты не требуются.

## Подтверждённые данные

Числовой источник — quantity_df и соответствующее происхождение. Точные статьи пользователя:

- «Дарбэпоэтин альфа (Аранесп),30мкг,шпр.» — строка Excel 47;
- «Дарбэпоэтин альфа (Аранесп),20мкг,шпр.» — строка Excel 48.

Расход — подтверждённая сумма января–сентября. План = «Утверждено», факт = «Факт по 1С», серия «отк:» = «Факт по норме» − «Факт по 1С». Для каждой пары филиал/статья каждый месяц нужен ровно один раз. Суммирование через Decimal без округления исходных чисел. По решению пользователя подписи показывают целые числа без десятичных знаков. Встроенные XLSX содержат вычисленные значения без предварительного округления; python-pptx записывает int/float, поэтому точное десятичное хранение не гарантируется.

Только отсутствующий августовский факт «Атырау Нурсая» по этим двум статьям (AM47/AM48) считается нулём по отдельному разрешению. Исключение действует только в модели слайда 5. Excel и quantity_df не изменяются; другие пропуски, ошибки, отрицательные/нечисловые значения блокируют экспорт. Нулевой план сохраняется, процент для него не вычисляется.

## Представление

В коде задан список 19 центров, соответствующий ранее согласованному образцу. Порядок одинаков для обеих статей. Справочник и имена листов сопоставляют подписи, в том числе «УК» и «Усть-Каменогорск (NL UK)». Нурсая 2 автоматически не добавляется.

Два ряда: препарат 30 мкг сверху, 20 мкг снизу. Слева центры, справа сумма только по показанным центрам; это явно подписано. Вместо коротких названий используются полные статьи. Все четыре редактируемые диаграммы и независимые XLSX создаются программно. Старые проценты не копируются. Ширина области столбцов пропорциональна числу центров до 19, область центрирована. План/факт подписаны вертикально; отрицательные отклонения отделены от названий центров. Формат подписей значений — целые числа.

## Результаты и проверки

Основной файл output/NL_пациенты_2026_слайд2.pptx содержит 4 показателя; тестовый output/NL_test_branch_counts_fixed.pptx — 20 слайдов, из них последние пять — препараты для 1/3/6/11/18 центров. Файлы создаются при отсутствии или обновляются после проверки. Прошлые презентации не используются для генерации.

Проверяются независимые месячные значения Excel на всех 19 центрах, категории, серии, отклонения, итоги, подписи, встроенные XLSX и геометрия. Проверены пропуски, ошибки, отрицательные/бесконечные значения, дубли, индексы, нулевой план и дробный расход. Проверка холодного запуска блокирует входные PPTX и повторное чтение бюджетов. Результаты PowerPoint фиксируются в STATUS.md.

Кэш формул не пересчитывается, интерактивный запуск Jupyter не проверен. Старое требование обязательных существующих PPTX из D-018 отменено D-019; оно вызывало ошибку первого запуска.




## Оформление диаграмм

Названия статей размещаются внутри рамок диаграмм, по центру графика, шрифт 9 pt. Отрицательные столбцы имеют красную заливку. Расчёты и данные встроенных XLSX не округляются.


Уточнение пользователя: третий столбец рассчитывается из суммы «Факт по норме» минус сумма «Факт по 1С» за январь–сентябрь, включая итоговые диаграммы. При отклонении < 0 столбец и метка красные; при > 0 столбец серый, метка зелёная (#008000); при нуле столбец серый, метка чёрная. Подписи статей вне рамок удалены: на каждый препарат остаётся только одна подпись внутри рамки.
