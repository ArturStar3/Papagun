# Визуальный стиль интерфейса

## Реализованная система Tauri UI — 2026-10-29

Дизайн для плотной финансовой работы: графитовая навигация `#18283D`, светлая рабочая поверхность `#F3F6F9`, белые панели `#FFFFFF`, основной текст `#17243A`, вторичный `#526176`, граница `#DCE4EC`, синий акцент `#275F9E`. Тёмная тема использует фон `#111A26`, панели `#1B2838`, текст `#EFF4F9`, границу `#35475B`, акцент `#76A9DF`. Типографика — Segoe UI Variable/Segoe UI; шкала 12/13/14/17/29 px. Отступы 4/8/12/16/20/26/34 px. Радиусы 6/7/9/13 px по иерархии.

Слева компактная навигация; рабочий поток сверху вниз: две книги, месяцы и филиалы, таблица статей, сохранение. Состояния выбора, загрузки, ошибки и успеха видимы текстом. Фокус выделяется контуром 3 px, модальное подтверждение удерживает клавиатурный фокус. Анимации ограничены 180 мс и отключаются при `prefers-reduced-motion`. При узком окне навигация становится иконной, панели переходят в одну колонку. Система реализована в `app/src/style.css`.

Таблица статей показывает единый каталог количественной книги: флажок, код и название. Выбранные позиции применяются к обеим книгам; названия финансовой книги в списке повторно не выводятся.

Нижеследующие исходные значения были предварительным предложением до реализации Tauri и заменены системой выше.

Статус: предложенная исходная система оформления. Изменяется последовательно после обратной связи пользователя. Стиль презентации задаётся отдельно её утверждённым образцом.

## Направление
Спокойный рабочий интерфейс на русском языке: светлый фон, читабельные данные, ясное основное действие, минимум декора.
Использовать стандартные диалоги выбора файлов Windows.

## Базовые значения
- Фон окна: #F5F7FA.
- Фон карточек и полей: #FFFFFF.
- Основной текст: #182230.
- Вторичный текст: #475467.
- Границы: #D0D5DD.
- Акцент и основная кнопка: #2563EB; текст на кнопке: #FFFFFF.
- Успех: #16794B.
- Предупреждение: #9A6700.
- Ошибка: #B42318.
- Шрифт: Segoe UI с системным запасным вариантом.
- Основной размер: 14 px; вспомогательный: 12 px; заголовок: 22 px.
- Отступы: 4, 8, 12, 16, 24, 32 px.
- Скругления: 8 px.
- Минимальная высота кнопок и полей: 36 px.

Хранить значения централизованно в теме, когда появится UI; не копировать произвольные цвета в отдельные виджеты.

## Компоновка
Верхняя область: имя приложения и краткое назначение.
Основная область: источники Excel и их состояние; затем место для будущих фильтров; затем результат проверки и подготовленные сводные сведения.
Нижняя область: прогресс, статус и основная кнопка «Создать презентацию».
Пустое место фильтров не заполнять выдуманными параметрами; до реализации раздел можно скрыть.

## Состояния
Начальное: выбрать файлы, экспорт недоступен.
Загрузка и обработка: видимый прогресс, запрет повторного запуска.
Готовность: сводка и доступный экспорт.
Ошибка: причина, расположение проблемы и доступное действие.
Успех: путь результата и возможность открыть файл.

## Согласованность и доступность
В каждом состоянии одно основное действие. Ошибки не обозначаются только цветом.
Клавиатурный фокус виден, порядок перехода логичен.
Проверять масштабирование Windows 100%, 125% и 150%, длинные русские подписи и изменение размера окна.
Полные технические трассировки не показывать в основном сообщении пользователю.
