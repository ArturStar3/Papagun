# Нагрузка на аппараты — аналог слайда 4

Дата: 2026-10-23.

По поручению пользователя в `excel_loading.ipynb` добавлен третий слайд итогового отчёта по образцу слайда 4 `Исходники/Презентация_NL_9 мес 2026.pptx`. Подтверждённая формула: **Количество пациентов / Количество аппаратов**.

Для данного прототипа используются сентябрьские значения `quantity_df`: строка Excel 14 «Количество пациентов» и связанная с ней строка 13 «Количество аппаратов» каждого центра. Это срез на конец девяти месяцев по аналогии со слайдом пациентов. В Караганде ЦАД на строке 13 написано «Количество аппаратов Караганда»; это явное допускаемое имя, координата строки сохраняется. Другие одноимённые строки не объединяются.

Плановая нагрузка = «Утверждено» пациентов / «Утверждено» аппаратов. Фактическая нагрузка = «Факт по 1С» пациентов / «Факт по 1С» аппаратов. В редактируемой диаграмме одна серия фактической нагрузки по 18 центрам образца, отсортированным по убыванию. В сводке показано фактическое число аппаратов; общие нагрузки рассчитываются как отношения сумм соответствующих числителей и знаменателей по показанным центрам. Представление в сводке и подписях — один знак после запятой; вычисления идут через Decimal без округления до вывода. Правило не переносится автоматически на другие показатели и периоды.

Пропуск, код ошибки Excel, отрицательное/дробное число пациентов или аппаратов, нулевой знаменатель и изменение статьи/происхождения блокируют экспорт. Центры и подписи берутся из образца и справочника; числовые показатели — только из переданного `quantity_df` с таблицей происхождения. Промежуточный одно-слайдовый PPTX создаётся во временной папке; штатный запуск сохраняет только итоговый и общий тестовый PPTX.

Общий тест расширен до 15 слайдов: по пять наборов для пациентов (1/3/6/11/18), процедур (1/3/6/11/19) и нагрузки (1/3/6/11/18). Проверены независимые сентябрьские ячейки строк 13 и 14, значения серии и встроенной XLSX, сводка, ошибочные входы, геометрия малых наборов, XML при объединении и сохранность исходников. При проверке модели исходные листы и повторный импорт заблокированы, изменение знаменателя в переданном DataFrame меняет результат.

Фактический запуск всех ячеек создал только `output/NL_пациенты_процедуры_2026_6.pptx` (3 слайда) и `output/NL_test_branch_counts_fixed_6.pptx` (15 слайдов). PowerPoint проверил все 18 слайдов без переполнений текста и переноса числовых подписей. Первоначально рамка сводки слайда 4 оказалась низкой для её текста; она увеличена и повторно проверена. Временные превью удалены. Интерактивный запуск Jupyter не выполнялся.
