# Нагрузка на аппараты — аналог слайда 4

Актуальная реализация: D-019, 2026-10-27. Слайд строится программно в notebook, входной PPTX не требуется.

Пользователь подтвердил формулу: количество пациентов / количество аппаратов. Для текущего прототипа — сентябрьские строки 14 и 13 quantity_df, отдельно для «Утверждено» и «Факт по 1С». Строка 13 Караганды ЦАД допускает название «Количество аппаратов Караганда». Числа пациентов/аппаратов целые неотрицательные; пропуски, ошибки, дроби и нулевые знаменатели блокируют экспорт.

Используется явный список 18 центров. Диаграмма показывает фактическую нагрузку по убыванию. Общие плановая/фактическая нагрузки рассчитываются отношениями соответствующих сумм пациентов и аппаратов по показанным центрам; аппараты в сводке — сумма фактического количества. Показатели рассчитываются через Decimal, отображение нагрузки — один знак после запятой, ROUND_HALF_UP. Новые колонки в quantity_df не добавляются.

Диаграмма, геометрия и сводка создаются с нуля. Связь с исходным PPTX исключена; рамка сводки рассчитана на весь текст. Тестовые наборы — 1/3/6/11/18, в общем тестовом файле они занимают слайды 11–15. Все значения и знаменатели независимо сверяются с Excel, проверяются встроенные XLSX, сортировка, сводка, геометрия и ошибочные входы. Формула и состав относятся к данному прототипу. Результаты PowerPoint и ограничения проверки записаны в STATUS.md.
