# Слайды 19–21: три позиции Гепарина и Надропарина

Основание: поручение от 2026-10-28, решение D-032. Визуальный пример — слайды 20–22 презентации NL за 9 месяцев. Номера нового отчёта отличаются на один, поскольку титульный слайд образца в него не включён.

## Источники и ключи

- Строка 59: код 211.13, точное наименование «Гепарин».
- Строка 60: код 211.13, точное наименование «Гепарин пробка».
- Строка 61: код 211.14, точное наименование «Надропарин (Фраксипарин) 0,4».

Данные берутся из переданных quantity_df/financial_df. У кода удаляются только краевые пробелы при сопоставлении; наименование сравнивается точно. Источники и DataFrame не исправляются. Строки Excel нужны для независимой проверки происхождения, а не вместо составного ключа выбора. На каждом слайде все три позиции остаются независимыми.

## Расчёты и макеты

19: количество, сумма января–сентября; ряды «План» = Утверждено, «Факт» = Факт по 1С, «отк:» = Факт по норме минус Факт по 1С. Для каждой статьи график по прежним 19 центрам и отдельный итог.

20: финансовые суммы января–сентября из financial_df, тыс. тенге; ряды нормы, факта 1С, их разности. Итоговый процент = сумма нормы / сумма факта 1С × 100; нулевой знаменатель — «н/д».

21: количество по 1/2/3 кварталам и 9 месяцам; норма, факт 1С, разность. Процент = факт 1С / норма × 100, красным при исходном отношении >100%; нулевой знаменатель — «н/д». Готовые периоды Excel не используются.

Три вертикальных блока в порядке Гепарин / Гепарин пробка / Надропарин. Заголовки, шрифт, цвета и редактируемые диаграммы соответствуют текущему генератору. Подписи центров в новых трёхблочных графиках — 8 pt без автоматического переноса; названия статей — 9 pt. Подписи значений целые, расчёты и встроенные XLSX без предварительного округления. Отрицательная разность: красные столбцы и метки; положительная: серые столбцы и зелёные метки.

## Разрешённые пропуски

Только для указанных составных ключей, по явному ответу пользователя:

- quantity_df: сентябрьский факт 1С обеих позиций 211.13 у 19 показанных центров — 38 пропусков;
- quantity_df: Утверждено Гепарина пробка за апрель–сентябрь у этих центров — 114 пропусков;
- quantity_df: августовский факт 1С Надропарина у Атырау Нурсая — один пропуск;
- financial_df: факт 1С Гепарина пробка за январь–сентябрь — 171 пропуск;
- financial_df: сентябрьский факт 1С Гепарина и Надропарина — 38 пропусков.

Заменяются только отсутствующие значения в модели: всего 153 количественных и 209 финансовых. Пропуски нормы, остальные пропуски и ошибочные значения блокируют расчёт.

## Проверка и выпуск

Проверки реализованы внутри notebook: независимые ячейки Excel строк 59–61, разделение одинакового кода по наименованию, краевые пробелы кода, отсутствующие/повторённые ключи, неизменность других позиций при изменении одной, разрешённые пропуски, модели, диаграммы/XLSX и геометрия трёх блоков. Пять наборов центров для каждого из трёх слайдов добавляются в конец общего теста. Фактический результат запуска и визуальной проверки записывается в STATUS.md.
