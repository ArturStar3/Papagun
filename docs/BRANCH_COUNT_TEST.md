# Общая проверка количества центров

Актуальная самостоятельная реализация: D-019 и расширения до D-033, 2026-10-28. Базовые шесть показателей приведены ниже; дополнительные группы перечислены после них. Все тесты находятся в excel_loading.ipynb. Слайды и диаграммы создаются программно, временные PPTX-шаблоны не используются.

Дополнительные тройки: 211.03/04 — тесты 31–45; 211.08/09 — 46–60; 211.07/10 — 61–75; 211.11/12 — 76–90; три позиции 211.13/14 — 91–105; расходные материалы 212.14, 212.23 и сумма 212.15–212.18 — 106–120. Каждая тройка содержит по пять наборов количественного, финансового и квартального слайдов.

Наборы вложенные, сначала выбираются самые длинные подписи, при равенстве сохраняется порядок явного списка. Это технические проверки, не пользовательские бизнес-фильтры. Значения — только из подготовленного DataFrame; синтетические значения используются исключительно для ошибочных входов и проверки распространения изменений.

Для каждого из 144 основных/тестовых слайдов проверяются число категорий, порядок, роли серий, значения, сводка, проценты (где применимо), встроенные XLSX, центрирование компактной области и границы фигур. Итог — 24 основных слайда / 83 диаграммы и 120 тестовых / 415 диаграмм, каждая со своей XLSX. Исходные значения всех шести показателей независимо сверяются с openpyxl. Проверяются пропуски, Excel-ошибки, неверные числа/месяцы/индексы, дубли и нулевые знаменатели.

Холодный запуск выполняется в несуществующую папку с запретом чтения внешних PPTX, исходных листов, повторного импорта и числовых бюджетов. Разрешён только справочник названий и проверка внутренних XLSX. Во время теста изменённые значения переданного DataFrame должны попасть в результат. Повторный запуск сохраняет число и структуру слайдов и оставляет ровно два файла. Дополнительно проверяются откат при ошибке замены второго файла и запрет записи в «Исходники».

RENDER_PREVIEWS=True включает PowerPoint только после построения. Превью и JSON временные, output содержит два постоянных PPTX. Фактические результаты последнего прогона — STATUS.md. Другие просмотрщики, новые составы центров и актуальность кэша Excel не проверены.
