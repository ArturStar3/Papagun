# Журнал решений

Не переписывать историю принятого решения молча: новое решение явно заменяет предыдущее.

## D-001 — Python и Windows EXE
Дата: 2026-10-10.
Статус: подтверждено пользователем.
Решение: приложение реализуется на Python и распространяется с исполняемым .exe.
Следствие: сборка и проверка в Windows входят в критерии готовности.

## D-002 — Последовательная подготовка данных
Дата: 2026-10-10.
Статус: подтверждено пользователем.
Решение: Excel загружается, данные очищаются и подготавливаются, затем используются для генерации презентации заданного формата.
Следствие: правила подготовки и отображения документируются отдельно.

## D-003 — Фильтры позже
Дата: 2026-10-10.
Статус: подтверждено пользователем.
Решение: UI предусматривает фильтры, перечень и поведение будут определены позже.
Следствие: не реализовывать предположительные бизнес-фильтры.

## D-004 — Техническая основа
Дата: 2026-10-10.
Статус: предложение.
Кандидаты: PySide6, openpyxl, python-pptx, PyInstaller.
Условия принятия: анализ исходных материалов, проверка поддерживаемых объектов и сборки.
Следствие: стек приложения пока не выбран и версии не закреплены. Для исследования Excel используются уже имеющиеся в среде pandas и openpyxl; это не утверждение полного стека приложения.

## D-005 — Исследование Excel в Jupyter через pandas
Дата: 2026-10-11.
Статус: подтверждено пользователем для текущего этапа исследования.
Основание: поручение создать ipynb и подключить Excel-таблицы через pandas.
Решение: исследование начинается в `excel_loading.ipynb`; чтение XLSX выполняется через pandas с движком openpyxl.
Последствия: исходники только читаются; результаты ячеек с содержимым таблиц не сохраняются в репозитории. Выбор библиотек интерфейса, расчётов и сборки EXE остаётся открытым.
