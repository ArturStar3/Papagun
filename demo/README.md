# Papagun Demo

После генерации кнопка «Открыть папку» в сообщении о готовности показывает каталог demo-презентации в Проводнике Windows.

Если предыдущий demo-отчёт открыт в PowerPoint и Windows запрещает его замену, новый файл сохраняется рядом с номером в имени. В сообщении о готовности показано фактическое имя; открытый отчёт остаётся без изменений.

Demo использует текущие исходники `app/`, но собирается в `demo/.build/` с отдельными именем приложения, идентификатором и Python-обработчиком. Основные исходники и артефакты сборки не изменяются. В каждый слайд итоговой презентации добавляются пять отдельных диагональных надписей с полным текстом:

> Данная демо-версия проекта является ознакомительной и не предназначена для использования

PPTX содержит `modifyVerifier`: PowerPoint должен открывать его с защитой от изменения и запрашивать пароль для редактирования. Пароль создаётся случайно для каждого отчёта и не сохраняется. Это не шифрование: редактор ZIP/OOXML может удалить защиту, поэтому абсолютный запрет изменения доступного пользователю PPTX технически невозможен.

Собрать на Windows из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File demo/build-demo.ps1
```

Результаты находятся в `demo/dist/`:

- `Papagun-Demo-Setup.exe` — автономный установщик.
- `papagun-demo.exe` — приложение для запуска рядом с `papagun-demo-engine.exe`.
- `papagun-demo-engine.exe` — локальный обработчик с водяным знаком.

Если переносимый `papagun-demo.exe` запущен во время сборки, Windows не позволяет заменить его. Установщик всё равно обновляется, а новая пара EXE сохраняется вместе в папке `demo/dist/portable-ГГГГММДД-ЧЧММСС/`. Запущенное приложение не закрывается и его файлы не перезаписываются.

Для проверки на локальных книгах NL:

```powershell
python -X utf8 demo/verify-demo.py
```

Проверка выбирает самый новый обработчик из `demo/dist/` и переносимых папок, создаёт `demo/.build/demo-qa.pptx` за первые два доступных месяца со всеми доступными филиалами и одной лекарственной статьёй. Она проверяет двенадцать страниц, полные подписи филиалов под углом 45° на графиках долей и сортировку графиков по доле или отклонению. Также проверяются период первых двух слайдов, пять наклонных надписей на каждой странице, `modifyVerifier` и неизменность обеих исходных книг. Установка на чистой Windows, парольный запрос в PowerPoint и полный проход через нативное окно пока не проверены.
